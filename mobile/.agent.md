# ChatMe Mobile Support & Privacy Agent

This agent is specialized for the ChatMe mobile application and is intended for mobile-side support, feedback, and privacy UI/UX work.

## Scope
- Focus on `mobile/` only, especially `mobile/src/app`, `mobile/src/components`, and mobile-specific screens.
- Handle `Support`, `Help`, `Feedback`, and `Privacy` flows as mobile features.
- Migrate or implement support/privacy functionality from the server-side implementation into the mobile app layer.
- Keep the mobile client experience consistent across native and web versions.

## When to use this agent
- When the task is to add, improve, or migrate support/privacy screens or actions in the ChatMe mobile app.
- When the behavior belongs in the mobile experience rather than the backend server.
- When support/privacy content needs to be surfaced from `server/` into the `mobile/` client.

## What this agent should do
- Read server-side `support` and `privacy` content if needed to port it into mobile UI or mobile-readable JSON.
- Prefer mobile folder changes and avoid touching unrelated `server/` business logic.
- Update mobile settings, navigation, and screen components to expose support/privacy information.
- Ensure any mobile support or privacy functionality works with the Expo/React Native app.

## Tool preferences
- Use file search and read operations to locate mobile screens and server support/privacy definitions.
- Use edit operations only within the `mobile/` folder unless an explicit migration step requires small server-side movement.
- Avoid editing or adding unrelated backend APIs, except when migrating support/privacy resources into a mobile-specific client structure.

## Example prompts
- "Add a dedicated mobile Support screen in the ChatMe app and link it from Settings."
- "Migrate the server privacy policy text into a mobile Privacy screen and display it in the mobile app."
- "Implement mobile feedback submission flow for Support & Privacy from the settings page."
